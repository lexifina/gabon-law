# Article 8

- Les épreuves écrites du concours profesionnel qui se dérouleront le 3 juin 1971 porteront sur les matières suivantes :

-Rédaction d'une procédure sur un thème donné (durée 3 heures, coefficient 2);

-Sécurité publique (durée 2 heures, coefficient 2);

-Renseignements généraux ( durée 2 heures, coefficient 2).
