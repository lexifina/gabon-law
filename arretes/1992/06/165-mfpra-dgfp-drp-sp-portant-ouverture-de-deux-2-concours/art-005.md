# Article 5

- Le programme de chaque concours est le suivant :

A/- Instituteurs principaux, 80 places :

- Pédagogie générale, coef. 1, durée 3 h ;

- Pédagogie spéciale, coef. 1, durée 3 h ;

- Culture générale, coef. 1, durée 3 h.

B/- Instituteurs, 150 places :

- Pédagogie générale ou spéciale, coef. 1, durée 3 h ;

- Culture générale, coef. 1, durée 3h ;

- Morale professionnelle, coef. 1, durée 3 h.
