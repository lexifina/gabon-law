# Article 3

- Le PTE N° 33/90, en deux lots, est défini comme suit :

Lot N° 1 de 10.000 hectares: carré ABCD de 10.000 m X 10.000 m.

Le point d'origine 0 est la borne astronomique de Bafounou ;

Le point A est situé à 15.600 m de 0 selon un orientement géographique de 332° ;

Le point B est situé à 10.000 m à l'Est géographique de A ;

Le point C est situé à 10.000 m au Nord géographique de B ;

Le point D est situé à 10.000 m à l'Ouest géographique de C ;

Le point A est situé à 10.000 m au Sud géographique de D et ferme le carré.

Lot N° 2 de 5.000 hectares

Le point d'origine 0 est la borne astronomique de Bafounou ;

Le point A, situé sur la rive droite de l'Ogooué est à 13.000 m de 0 selon un orientement géographique de 350° ;

Le point B est situé à 4.400 m de A selon un orientement géographique de 290° ;

Le point C est situé à 10.000 m de B selon un orientement géographique de 20° ;

Le point D est situé à 4.400 m de C selon un orientement géographiquede 110° ;

La limite DA suit la rive droite de l'Ogooué et ferme le polygone.
