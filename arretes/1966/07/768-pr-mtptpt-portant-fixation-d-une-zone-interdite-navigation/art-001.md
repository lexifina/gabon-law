# Article premier

- Dans le cadre des études du Port d'Owendo et pour sauvegarder le matériel mis en place, toute navigation est interdite dans la zone limitée par :

La côte et les droites passant par les points suivants

Pont A : Balise Owendo 0° 17' 10" N.

Pont A : Balise Owendo, 0° 17' 10" N, 9° 30' 29" E.

Point B : à 550 mètres dans le 228° du point « A ».

Point C : à 1.100 mètres dans le 280° du point « B ».

Point D : la côte à 26' du point « C ».
