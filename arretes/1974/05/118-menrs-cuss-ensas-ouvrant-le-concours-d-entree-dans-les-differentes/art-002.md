# Article 2

Le nombre de bourses mises au concours est de cent douze (112), réparties comme suit :

Cycle C : Dix (10) pour le diplôme élémentaire d'Infirmiers-comptables ;

Cycle C: Quinze (15) pour le diplôme élémentaire d'infirmiers, Infirmières ;

Cycle B : Vingt -cinq (25) pour le diplôme d'Etat d'Infirmiers, Infirmières ;

Cycle B : Dix (10) pour le diplôme d'Etat de Sages-Femmes ;

Cycle B : Cinq (5) pour le diplôme d'Etat de Préparateur en Pharmacie :

Cycle B : Cinq (5) pour le diplôme d'Etat d'Adjoints techniques de Laboratoire ;

Cycle B : Cinq (5) pour le Diplôme d'Etat d'Adjoints techniques de Radiologie ;

Cycle B : Douze (12) pour le diplôme d'Etat d'Adjoints techniques d'Assainissement ;

Cycle B : Dix (10) pour le Diplôme d'Etat d'Aides sociaux, Aides sociales ;

Cycle B : Quinze (15) pour le Diplôme d'Etat d'Aides éducatrices préscolaires.
