# Article 3

- La retenue sur les recouvrements concerne les natures d'impôts suivants :

- Impôt sur les sociétés non pétrolières ;

- Impôt sur le revenu des personnes physiques ;

- Taxe sur les biens de mainmorte ;

- Impôt sur le chiffre d'afïaire intérieur ;

- Taxe sur les transactions ;

- Versement forfaitaire sur les salaires.
