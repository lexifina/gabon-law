# Article 2

- Ce concours comportera :

- Un sujet d'ordre général - durée 3 heures (coefficient 3) ;

- Un sujet d'histoire ou de géographie (programme de classe de l re ) - durée 2 heures (coefficient 2) ;

- Langue vivante (anglais, allemand, espagnol, du niveau de classe de ire (coefficient 1) ;

- Seuls les points au-dessus de 10 étant pris en considération.

Epreuves orales qui se dérouleront à Libreville pour les candidats déclarés admissibles :

- une conversation d'un quart d'heure avec le Jury d'examen ;

- des épreuves d'aptitudes physiques ;

- une épreuve de langue vivante (anglais - allemand - espagnol).
