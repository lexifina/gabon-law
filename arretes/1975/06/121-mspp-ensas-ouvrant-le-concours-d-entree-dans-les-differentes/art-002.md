# Article 2

- Le nombre de bourses au concours est cent cinquante-sept (157), réparties comme suit :

Cycle C :

- Cinq (5) pour le diplôme élémentaire d'infirmiers-comptables.

- Vingt (20) pour le diplôme élémentaire d'infirmiers-infirmières.

Cycle B :

- Cinquante (50) pour le diplôme d'Etat d'infirmiers-infirmières.

- Vingt (20) pour le diplôme d'Etat de sages -femmes.

- Sept (7) pour le diplôme d'Etat de préparateurs en pharmacie.

- Dix (10) pour le diplôme d'Etat d'adjoints techniques de laboratoire.

- Cinq (5) pour le diplôme d'Etat d'adjoints techniques de radiologie.

- Dix (10) pour le diplôme d'Etat d'adjoints techniques d'assainissement.

- Quinze (15) pour le diplôme d’Etat d'aides sociaux, aides sociales.

- Quinze (15) pour le diplôme d'Etat d'aides éducatrices préscolaires.
