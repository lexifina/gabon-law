# Article 3

- L'examen comportera les épreuves suivantes :

Epreuves écrites :

- Sécurité publique - durée 2 heures (coefficient 3) ;

- Police judiciaire - durée 2 heures (coefficient 2).

Epreuves orales :

- une conversation d'un quart d'heure avec le Jury d'examen ;

- instruction civique - durée 2 heures ;

- armement ;

- épreuve d'aptitude physique

- épreuve de commandement.
