# Article 88

- Seuls sont comptés, les bulletins fournis par l'administration. Sont comptabilisés comme bulletins nuls :

- les bulletins blancs ;

- les bulletins sur lesquels le votant s'est fait connaître ;

- les bulletins trouvés sans enveloppe ou dans des enveloppes non réglementaires ;

- les bulletins ou enveloppes portant des mentions injurieuses pour les candidats ou pour les tiers ;

- les bulletins multiples et contradictoires placés dans une même enveloppe ; - les bulletins sur lesquels le nom d'un ou de plusieurs candidats a été rayé ou ajouté.
