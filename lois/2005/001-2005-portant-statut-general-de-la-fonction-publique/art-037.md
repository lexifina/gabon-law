# Article 37

- Les organes centraux de gestion se répartissent en :

- directions générales pour :

- les agents civils de l’Etat ;

- les magistrats les greffiers ;

- les militaires des forces de défense ;

- les agents des forces de sécurité ;

- les agents de l’administration pénitentiaire ;

- offices pour les agents des Fonctions Publiques :

- parlementaire ;

- hospitalière ;

- de l’éducation ;

- locale.

Les attributions, l’organisation et le fonctionnement des organes cités ci- dessus font l’objet de textes particuliers.
