# Article 3

- Les inscriptions seront prises jusqu'au 10 mars 1967 inclus. A cet effet, les candidats devront adresser au DIRECTEUR DU LYCEE TECHNIQUE, à Libreville, un dossier comprenant :

- Une demande manuscrite mentionnant l'option choisie ;

- Un extrait d'acte de naissance ou jugement supplétif ,

- Un certificat de scolarité.

Art 4. - Les candidats peuvent opter entre les spécialités suivantes :

- Option A : SECRETARIAT ; - Option A' SECRETARIAT ; - Option B : COMMERCE ; - Option C : COMPTABILITE.

Ils devront mentionner sur leur demande la langue vivante choisie.

Les candidats inaptes à l'épreuve obligatoire d'édu- cation physique devront fournir un certificat médical attestant leur inaptitude.
