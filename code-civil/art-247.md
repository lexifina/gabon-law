Si les deux époux ont été déclarés de mauvaise foi par le tribunal, le mariage nul est réputé n'avoir jamais existé tant dans les rapports entre les époux entre eux que dans leurs rapports avec les tiers.
Toutefois, les enfants issus d'un mariage déclaré nul demeurent légitimes, même si leurs père et mère n'étaient pas de bonne foi. La garde de l'enfant sera décidée par le tribunal.
