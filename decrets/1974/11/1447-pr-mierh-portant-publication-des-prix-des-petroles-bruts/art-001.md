# Article premier

- Les prix des pétroles bruts gabonais servant de base au calcul de la redevance proportionnelle sont fixés comme suit à compter du 20 octobre 1973 :

- qualité Mandji mélange : 30°, 8 API 6,60 dollars US-baril ;

- qualité Gamba : 31° API 7,40 dollars US-baril.

Ces prix ont susceptible d'être modifiés par décrets pris sous la même forme, compte tenu de l'évolution des prix semblables du marché.
