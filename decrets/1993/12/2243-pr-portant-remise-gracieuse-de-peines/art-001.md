# Article premier

Une mesure générale de grâce est accordée, dans les conditions précisées aux articles 2 et 3 ciaprès, à l'ensemble des condamnés de droit commun.

Sont toutefois exclus du bénéfice de ces dispositions les détenus condamnés pour :

- homicide volontaire (articles 223 à 229 du code pénal);

- association de malfaiteurs (articles 193 à 195 du code pénal);

- vol à main armée avec prise d'otages; tortures ou viol ;

vol avec port d'armes ; vol avec violences (article 295 nouveau du code pénal);

- détournement de fonds publics (article 141 du code pénal).
