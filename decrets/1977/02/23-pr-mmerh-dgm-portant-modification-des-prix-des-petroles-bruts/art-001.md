# Article premier

- Les prix postés applicables aux pétroles bruts gabonais pour compter du 1er janvier 1977 sont les suivants : -

- qualité Mandji 29° API : 14,31 US $/baril,

- qualité Gamba 31° API : 14,81 US $/baril.

Ces prix sont susceptibles d'être modifiés par des décrets pris sous la même forme, compte tenu de l'évolution des prix semblables du marché.
