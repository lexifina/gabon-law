# Article 3

- Les propriétés bâties ou non bordant les artères ci-après désignées devront être obligatoirement bordées en façades principales de poteaux en béton ou en fer profilés reliés entre eux par des fils de fer galvanisés un treillis métallique et doublés d'une haie vive. Celle-ci devra être prolongée sur toutes les limites des propriétés :

- Boulevard Quaben ;

- Toutes les rues intérieures et limitrophes aux sections Q et QA ;

- Rue Pierre-Barro ;

- Rue Joseph-Deemin ;

- Boulevard Léon-MBA ;

- Avenue Vincent-Nkounah ;

- Boulevard Bessieux ;

- Avenue Bouët ;

- Boulevard Frères-de-Bruchart ;

- Rue Marc-Ndouma ;

- Boulevard Yves-Digo ;

- Rue Jacques-Akérémy ;

- Rue Gaston-Ndjogoni ;

- Rue Derrière-l'Hôpital ;

- Boulevard de la République.
