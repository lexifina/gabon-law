# Article premier

A l'occasion de la fin de l'année 1994. une mesure générale de grâce est accordée, dans les conditions précisées aux articles 2 et 3 ci-après, à l'ensemble des condamnés de droit commun n'ayant subi aucune sanction disciplinaire durant leur détention. Sont toutefois exclus du bénéfice de ces dispositions. les détenus condamnés pour :

- détournement de fonds publics (article 141 du code pénal);

- association de malfaiteurs (articles 193 à 195 du code Pénal);

homicide volontaire (articles 223 à 229 du code pénal). vol à main armée avec prise d'otage: vol avec tortures corporelles ou viol:

vol avec port d'armes: vol avec simples violences (article 295 nouveau du code pénal)
