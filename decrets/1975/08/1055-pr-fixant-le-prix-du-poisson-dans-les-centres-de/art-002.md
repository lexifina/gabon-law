# Article 2

- Le prix de vente du poisson frais à la production dans les ports de pêche et les débarcadères par les armements de pêche installés au Gabon et les pêcheurs artisanaux est fixé comme suit :

1re catégorie : (Bécunes, poissons rouges, soles, turbots, limandes, dorades roses, raies, rougets, congres) ............ 200 F le kilo

2e catégorie : (Bossus, capitaines, disques, bars, dorades, grises, barbillons, faux thons, etc.).................................180 F le kilo

3e catégorie : (Machoirons, friture) ................................................................................................................. 150 F le kilo

4e catégorie : (Sardines, sardinelles, requins) .................................................................................................. 120 F le kilo
