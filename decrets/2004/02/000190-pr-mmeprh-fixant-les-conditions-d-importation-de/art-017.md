# Article 17

L’exploration de diamants se fait sur la base d’un document administratif dont le modèle est arrêté par le Ministre. Ce document comporte :

- le nom de l’exportateur et du destinataire des diamants ;

- le numéro de série du certificat du Processus de Kimberley ;

la date d’exportation des diamants ;

- la signature de l’exportateur attestant de l’exactitude de tous les renseignements relatifs à l’exportation.
